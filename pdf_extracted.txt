Pembuatan Aplikasi Berbasis Multimedia Menggunakan Visual Studio dan SQL Server 
 
NARASI PROYEK 
Perkembangan teknologi informasi telah mengubah cara masyarakat dalam mengelola data dan menyampaikan 
informasi. Saat ini berbagai organisasi, sekolah, UMKM, komunitas, dan lembaga pelayanan membutuhkan 
aplikasi yang tidak hanya mampu mengelola data tetapi juga mampu menyajikan informasi secara menarik 
melalui unsur multimedia seperti gambar, audio, video, animasi, dan grafik. 
Sebagai calon Software Developer, Anda diminta untuk merancang dan membangun sebuah Aplikasi Berbasis 
Multimedia yang dapat membantu menyelesaikan permasalahan nyata di lingkungan sekitar. 
Aplikasi yang dibuat harus mampu: 
• 
Mengelola data menggunakan database.  
• 
Menampilkan informasi dalam bentuk multimedia.  
• 
Memiliki antarmuka yang mudah digunakan.  
• 
Menerapkan prinsip CRUD (Create, Read, Update, Delete).  
• 
Menyimpan dan menampilkan data secara dinamis.  
• 
Memiliki nilai manfaat bagi pengguna.  
Proyek ini dikerjakan secara mandiri sebagai bentuk unjuk kompetensi akhir mata pelajaran Pemrograman 
Multimedia. 
 
TANTANGAN PROYEK 
Buatlah sebuah aplikasi desktop berbasis Windows Forms menggunakan C# pada Visual Studio yang 
memanfaatkan minimal 3 unsur multimedia dan database SQL Server. 
Aplikasi harus menyelesaikan masalah nyata yang ada di lingkungan sekolah, masyarakat, UMKM, komunitas, 
atau organisasi.
